# 애니메이션 도트 화풍 초상화

사용자가 첨부한 보랏빛 애니메이션 도트 그림을 참고해 내장 ImageGen으로 릴리아와 로웬을 다시 제작했다. 밝은 눈 하이라이트, 가는 선택적 윤곽, 보라색 명암과 디더링을 적용했다. 기존 머리색과 복장, 인물 정체성은 유지했다.

최종 PNG는 이 폴더의 Lilia.png, Rowen.png이며 기존 게임 리소스 LiliaDungeon.png, RowenDungeon.png에도 반영했다. 알파, Point 필터, 무압축, 밉맵 없음 설정을 유지한다. 이전 게임 이미지는 Lilia-before.png, Rowen-before.png로 보존했다.

## 게임 적용 확인

실제 1920×1080 및 1024×768 Game View에서 대사 13줄과 초상화를 확인했다. 얼굴이 이름표에 가려지지 않으며 모든 본문은 overflow=False였다. 마지막 소환 후 장면에서 rowenVisible=False를 확인했다. 이번 DialogueInteraction 자동 테스트 필터는 0개를 반환했으므로 통과 수를 주장하지 않는다. 이미지 리소스 교체 외에 대화 코드나 씬은 변경하지 않았다.
