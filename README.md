# 마왕님은 공사중

**던전을 건설하고 하수인을 지휘하며, 직접 침입자를 막아내는 싱글플레이 2D 탑다운 액션·던전 방어 게임입니다.**

Unity 기반 PC 프로토타입으로, 전투 전의 공간 설계와 병력 배치가 전투 중 마왕의 직접 조작과 이어지는 플레이를 목표로 합니다.

## 핵심 플레이

> 던전 확장·하수인 배치 → 침입 방어 → 보상 선택·시체 회수 → 병력 보충·시설 투자 → 다음 침입 준비

- **던전 건설:** 기존 공간에 방과 복도를 연결하고 시설·함정을 배치합니다.
- **하수인 운용:** 근접·원거리·지원 역할의 병력을 소환하고 방별 수용량에 맞춰 배치합니다.
- **직접 전투:** 마왕을 조작해 기본 공격, 혈파, 혈막과 회피로 방어에 개입합니다.
- **시체 회수와 소환:** 적의 시체를 소환소로 운반해 소환 스택을 얻고 병력을 보충합니다.
- **경제와 성장:** 금화·혈액·혈석을 관리하고 시설과 기술에 투자합니다. 하수인 유지에는 혈액이 필요합니다.
- **공유 체력:** 마왕과 던전 코어가 체력을 공유하며, 공유 체력이 소진되면 패배합니다.

기본 구성은 5웨이브 방어를 목표로 합니다. 침입 중에는 건설과 신규 소환이 제한되며, 준비 단계에서 다음 전투를 정비합니다. 프로토타입 개발 중이므로 콘텐츠와 밸런스는 변경될 수 있습니다.

## 개발 환경

| 항목 | 구성 |
| --- | --- |
| Unity Editor | **6000.6.2f1** |
| 언어 | C# |
| 렌더링 | Universal Render Pipeline 17.6.0 / 2D Renderer |
| 입력 | Input System 1.20.0 |
| UI | uGUI / TextMeshPro |
| 주요 패키지 | 2D Tilemap, 2D Animation, Localization |
| 테스트 | Unity Test Framework 1.8.0 / PlayMode 테스트 |

에디터 버전은 `ProjectSettings/ProjectVersion.txt`, 직접 의존성은 `Packages/manifest.json`을 기준으로 합니다.

## 실행 방법

1. Unity Hub에서 **6000.6.2f1** 에디터를 설치합니다.
2. 저장소를 내려받은 뒤, Unity Hub에서 `Assets`, `Packages`, `ProjectSettings`가 있는 프로젝트 루트를 추가합니다.
3. 프로젝트를 열고 패키지 복원과 에셋 임포트가 완료될 때까지 기다립니다.
4. `Assets/Scenes/MainMenu.unity`를 엽니다.
5. **Play**를 누르고 타이틀 메뉴에서 새 게임을 시작합니다.

현재 빌드에 등록된 씬 순서는 다음과 같습니다.

| 순서 | 씬 | 용도 |
| --- | --- | --- |
| 0 | `MainMenu` | 타이틀, 새 게임 및 이어하기 |
| 1 | `Story` | 도입 스토리 |
| 2 | `InGame` | 튜토리얼 및 던전 플레이 |

전체 시작 흐름을 확인할 때는 `MainMenu`부터 실행합니다.

## 기본 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 | 기본 공격 |
| Q | 혈파 |
| R | 혈막 |
| Space | 회피 |
| F | 시설 상호작용, 시체 들기·내려놓기 |
| 하수인을 길게 누른 뒤 이동 | 하수인 재배치 |
| Esc | 일시정지 메뉴 |

## 프로젝트 구조

```text
Assets/
├── Scripts/
│   ├── Actors/        # 체력, 상태 효과, 캐릭터 공통 표현
│   ├── Dungeon/       # 던전 공간, 건설, 시설·함정 배치
│   ├── Gameplay/      # 웨이브, 튜토리얼, 게임 진행
│   ├── Minions/       # 하수인과 침입자 행동
│   ├── Persistence/   # 저장 데이터와 세션 관리
│   ├── Player/        # 이동, 전투, 소환, 카메라
│   └── UI/            # 메뉴, HUD, 상호작용 패널
├── Scenes/            # MainMenu, Story, InGame
├── Data/              # 게임 데이터 에셋
├── Prefabs/           # 캐릭터, 시설, UI 프리팹
├── Editor/            # 에디터 전용 도구
├── Settings/          # 렌더링과 입력 등 설정 에셋
└── Tests/PlayMode/    # 게임 시스템 테스트
Docs/                  # 설계, 구현 기록, FGT 문서
ArtSources/            # 아트 원본과 제작·임포트 기록
Tools/                 # 제작, 점검, 프리뷰용 스크립트
Packages/              # 패키지 의존성과 버전 잠금
ProjectSettings/       # Unity 프로젝트 설정
```

런타임 코드는 `DarkLord.Runtime`, PlayMode 테스트는 `DarkLord.PlayModeTests` 어셈블리로 구성됩니다. 에셋을 추가하거나 이동할 때는 대응하는 `.meta` 파일도 함께 관리합니다. `Library`, `Temp`, `Logs` 등 자동 생성 폴더는 버전 관리 대상에서 제외합니다.

## 테스트 및 빌드

Unity의 Test Runner에서 **PlayMode** 테스트를 실행할 수 있습니다. 전투, 건설, 웨이브, 튜토리얼, 경제, 저장·불러오기 등의 테스트가 `Assets/Tests/PlayMode`에 있습니다.

빌드는 **File → Build Profiles**에서 PC 대상 플랫폼을 선택하고, 씬 목록에 `MainMenu`, `Story`, `InGame`이 위 순서로 활성화되어 있는지 확인한 뒤 진행합니다. 대상 플랫폼에 필요한 빌드 모듈은 Unity Hub에서 설치합니다.

개별 기능의 검증 내역과 알려진 실패는 `Docs/AI`의 관련 구현 문서를 참고합니다. 이 README 작성 과정에서는 테스트나 빌드를 실행하지 않았습니다.
