# 저장과 이어하기

- 시작 씬: `Assets/Scenes/MainMenu.unity`. 새 게임 버튼에서 3개 저장 공간 중 하나를 선택한다.
- 읽을 수 있는 저장 기록이 있으면 이어하기 버튼이 표시된다. 이어하기 화면에서 불러올 공간을 선택한다.
- 새 게임 선택만으로 기존 파일을 삭제하지 않는다. 기존 공간 선택 시 안내하며, 해당 새 게임을 처음 수동 저장할 때 기존 기록을 덮어쓴다.
- Esc 일시정지 메뉴의 저장 버튼으로 선택한 공간에 저장한다. SampleScene을 직접 실행한 경우 최초 저장 시 공간을 선택한다.
- 저장 후 플레이하거나 상태가 바뀌면 미저장 상태가 된다. 미저장 상태에서 메인 메뉴 복귀 / 게임 종료 / 플레이어 애플리케이션 종료를 시도하면 저장 후 나가기, 저장 없이 나가기, 취소를 선택한다. 저장 실패 시 종료하지 않고 오류를 표시한다.
- 자동 저장은 하지 않는다. Unity 에디터의 강제 Play 중단과 프로세스 강제 종료에는 게임 UI 경고를 띄울 수 없다.

## 편집할 UI

- `Assets/Prefabs/UI/SaveSlotPanel.prefab`: 저장 공간 3개, 기록 요약, 취소, 덮어쓰기 확인.
- `Assets/Prefabs/UI/PausePanel.prefab`: 저장 버튼과 결과 메시지. 프리팹 내부 콜백은 `PausePanelBindings`가 씬 `GameMenu`에 전달한다.
- 종료 경고는 SampleScene의 Main Menu > Quit Confirmation에서 편집한다.
- 메인 화면의 새 게임 / 이어하기는 MainMenu 씬에서 편집한다. 이어하기가 표시될 때 새 게임 / 이어하기, 설정 / 종료 순서로 2×2 배치된다. 저장 기록이 없어 버튼이 3개이면 기존 세로 배치를 유지한다.
- `SaveUiSetup`은 최초 설치용이다. 이미 설정된 씬을 다시 생성하지 않도록 막아두었으므로 이후 수정은 기존 프리팹 / 씬에서 수행한다.

## 데이터

`Application.persistentDataPath/Saves/slot1.json` ~ `slot3.json`에 JSON으로 저장한다. 이전 기록은 `.bak`으로 유지하며, 주 파일을 읽을 수 없으면 정상 백업을 확인한다. `.tmp`에 쓰기와 디스크 flush를 마친 뒤 파일을 교체한다. 알 수 없는 형식 버전과 불완전한 데이터는 불러오지 않는다.

저장 대상은 플레이 시간, 자원, 주인공 위치 / 체력, 코어 체력, 타일 상태, 건설 구역 / 완료 여부 / 남은 건설 큐, 입구, 함정, 생산 건물 위치 / 자산 GUID / 체력 / 잔해 / 마지막 생산 라운드, 호위병 위치 / 체력 / 주둔 위치 / 복귀 명령, 웨이브 번호 / 상태 / 남은 생성 수 / 살아 있는 적이다. 건설 디자인은 BuildItemDefinition 자산 GUID로 식별하므로 자산 이름 변경에 영향받지 않는다. 전투 애니메이션, 현재 공격 타이밍과 탐색 경로는 불러온 상태를 기준으로 다시 계산한다.

## 검증

`SaveGameTests`는 실제 사용자 저장 폴더에 쓰지 않고 임시 폴더에서 3개 공간 독립성, 백업 복구, 잘못된 형식과 쓰기 거부, 게임 상태 왕복 복원, 일시정지 저장 버튼, 종료 경고 및 새 게임의 공간 선택을 확인한다. 테스트 결과는 `Logs/GameplayTests.xml`에서 확인할 수 있다.
