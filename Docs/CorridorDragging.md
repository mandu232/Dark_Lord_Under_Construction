# 드래그 복도 건설

2026-10-06. **B → 방 → 복도**를 선택합니다. 건설창이 숨겨지고 줌 아웃됩니다.

1. 기존 방이나 복도의 완성된 바닥에서 좌클릭을 누릅니다.
2. 누른 채 끝점까지 드래그합니다. 미리보기는 폭 3칸입니다.
3. 같은 축이면 직선, 축이 어긋나면 긴 축을 먼저 연결하는 ㄱ자 경로가 됩니다.
4. 마우스를 놓으면 초록색 경로를 건설 예약합니다. 타일은 시작 쪽의 연결된 바닥에서 순차적으로 열립니다.
5. 우클릭은 현재 드래그와 선택을 취소하고 건설창·원래 줌을 복원합니다. 이미 예약한 복도는 유지됩니다.

기존 방과 복도의 바닥·소유권은 유지합니다. 새 암석 타일만 예약하므로 방을 통과해도 방의 파수꾼 처치 규칙은 유지됩니다. 지도 경계·기반암·미완성 예약 구역과 겹치는 경로는 거절합니다. 같은 지점 또는 새 타일이 없는 경로는 생성하지 않습니다.

끝점을 빈 암석에 지정해 복도를 뻗은 뒤 그 끝에 5×5 또는 7×7 방을 붙일 수도 있습니다. 방 두 개가 이미 있으면 각 방 바닥을 시작점과 끝점으로 지정합니다.

설정은 Assets/Data/Construction/Corridor.asset입니다. 방 탭에는 방 두 종류와 복도 한 항목을 표시하며 가로·세로 고정 길이 항목은 사용하지 않습니다. 초기 입구 통로의 기존 고정 구역과 이전 데이터는 호환성을 위해 유지합니다.

복도 프리팹은 Assets/Prefabs/Dungeon/CorridorTileDesign.prefab입니다. 원점이 중앙인 1×1타일(2×2 월드 유닛) 디자인으로, 전체 복도가 완성된 뒤 새로 연 타일마다 생성됩니다. ㄱ자 바운딩 박스 전체를 채우지 않습니다. 프리팹을 교체할 때 통로를 막는 Collider를 추가하지 마세요.

검증: PlayMode 83/83 통과. 드래그/놓기/우클릭 실제 입력, 폭 3칸, 길이 변경, ㄱ자 경로 밖 타일 유지, 예약 중복·경계 거절, 방 소유권 유지, 완성 후 경로 탐색을 확인했습니다.
