# 마왕님은 공사중 FGT 진행 계획

작성일: 2026년 11월 1일  
상태: 실행 전 계획서  
검증 주제: 마왕의 직접 전투와 하수인 배치를 결합한 방어 전투 루프

## 목적과 범위

플레이어가 마왕과 하수인의 역할을 이해하고, 전투 결과를 바탕으로 다음 웨이브의 전략을 수정하는지 확인한다. 전투 뒤 시체 회수와 소환이 다음 방어를 준비하는 동기로 이어지는지도 관찰한다.

테스트 범위는 하수인 배치 → 직접 전투 → 침입 방어 → 시체 회수와 소환 및 보상 선택 → 다음 방어 준비이다. 전체 경제의 장기 균형, 전체 스토리, 5웨이브 완주율은 이번 검증의 범위에 포함하지 않는다.

현재 구현에는 시체를 소환소로 운반해 얻는 스택 소환과 마나를 사용하는 소환이 함께 있다. 기록할 때 두 경로를 구분한다. 현재 웨이브 보상은 방·시설·함정 아이템 및 자원 계열이며, 과거 문서의 증강 카드 선택을 이번 테스트의 전제로 삼지 않는다.

## 검증 질문

| 번호 | 질문 | 관찰 근거 |
|---|---|---|
| H1 | 마왕의 직접 전투와 하수인의 역할을 이해하는가 | 개입 위치와 시점, 공격·스킬 사용, 역할에 대한 사후 설명 |
| H2 | 전투 결과를 다음 준비에 반영하는가 | 배치·병력·전투 위치·보상 선택의 변화와 그 이유 |
| H3 | 시체 회수와 소환이 다음 전투 준비로 이어지는가 | 회수·운반·스택 획득·소환·새 병력 활용, 보람과 번거로움에 대한 설명 |

H1~H3은 검증할 가설이며 확인된 결과가 아니다. 행동을 하지 않았다는 이유만으로 이해 실패로 판정하지 않는다. 필요를 느끼지 못했거나 기회가 없었는지 확인한다.

## 참가자와 운영

- 본 테스트 참가자 최소 3명. 참가자 코드는 P01, P02, P03을 사용한다.
- 싱글플레이 개별 테스트로 진행하며 앞 참가자의 플레이나 공략을 보지 않도록 한다.
- 액션·방어·경영 게임 경험을 사전 기록한다. 가능하면 경험 수준이 다른 사람을 포함하되 경험에 따른 차이를 기록한다.
- 진행자 1명. 가능하면 관찰자 1명을 추가한다. 혼자 진행하면 핵심 사건만 짧게 기록하고 종료 직후 보충한다.
- 1명당 약 30분, 교체와 초기화에 5분. 3명 전체 약 105분을 확보한다.
- 참가자는 언제든 중단할 수 있다. 녹화·녹음은 사전 동의를 받은 경우에만 하며 미동의 시 메모로 진행한다. 제출물에는 실명 대신 코드를 사용한다.

테스트 일시: __________  장소: __________  진행자: __________  관찰자: __________

## 동일한 시작 조건

본 테스트 전 예비 플레이 1회로 실제 소요 시간과 진행 가능 여부를 확인한다. 다음은 준비할 조건이며 준비 완료를 뜻하지 않는다.

- 같은 빌드와 PC·입력 장치, 같은 화면 설정을 사용한다. 빌드 파일명 또는 커밋과 실행일을 기록한다.
- 기본안은 보통 난이도, 정상 튜토리얼 완료 직후 일반 1웨이브 시작 전 상태이다. 예비 플레이에서 시간이 부족하거나 진입이 어렵다면 조건을 조정하고 3명 모두 같은 조건으로 시작한다.
- 같은 자원·체력·병력·시설·입구·아이템 상태를 가진 별도 테스트 저장본을 복사해 사용한다. 개인 저장을 덮어쓰지 않는다.
- 실제 튜토리얼을 완료해 만든 저장본을 우선 사용한다. 스토리 건너뛰기만으로 튜토리얼이 완료되었다고 간주하지 않는다.
- 예비 플레이에서 마왕 공격·스킬·회피, 하수인 배치, 시체 운반·소환, 보상 선택과 다음 웨이브 진입이 가능한지 확인한다.
- 보통 난이도의 자동 침입 타이머와 준비 시간 압박도 기록한다. 일시정지나 조기 시작을 허용한다면 모두에게 같은 규칙을 적용한다.
- 무작위 결과를 고정할 수 있으면 같은 조건을 사용한다. 고정 기능이 없다면 코드 변경 없이 등장 병과·소환 결과·보상 후보를 기록하고 비교의 한계로 남긴다.
- 진행자가 상태를 초기화하거나 게임을 중단할 방법을 확인한다. 테스트 세션 도중 빌드와 규칙을 바꾸지 않는다.

## 1인 진행 순서

| 단계 | 시간 | 진행 내용 |
|---|---|---|
| 안내와 사전 질문 | 2분 | 목적, 중단 가능, 기록 동의, 장르 경험 확인 |
| 연습 | 3분 | 이동·조준·공격·스킬·회피와 배치 조작 연습. 내용과 도움 기록 |
| 본 플레이 | 최대 20분 | 동일한 시작 상태에서 1~3웨이브를 목표로 플레이 |
| 사후 설문과 인터뷰 | 5분 | 참가자가 먼저 설문 작성 후 행동의 이유 확인 |

연습 종료 후 본 플레이용 시작 상태로 다시 초기화해 연습 중 손실과 자원 소비가 영향을 주지 않게 한다. 연습에서 알려준 것은 본 플레이의 자력 발견으로 계산하지 않는다.

본 플레이는 3웨이브 완료, 패배, 20분 경과, 참가자의 중단 요청, 진행 불가능한 오류 중 먼저 발생한 조건에서 종료한다. 3웨이브 완주는 의무가 아니다. 실패나 시간 초과도 결과다. 본 플레이 중 재시작은 기본적으로 하지 않으며, 기술 오류로 재개할 경우 복구 위치와 소요 시간을 기록한다.

## 진행자가 읽을 안내

“게임의 문제와 개선할 부분을 찾기 위한 테스트입니다. 플레이 실력을 평가하지 않습니다. 약 30분 동안 진행하며 언제든 중단하셔도 됩니다. 평소 게임을 하듯 플레이해주세요. 전투 중 계속 말하지 않으셔도 됩니다.”

“목표는 마왕과 하수인을 활용해 침입을 막고 다음 침입을 준비하는 것입니다. 가능한 범위에서 3웨이브까지 진행해주세요. 어떤 준비를 하고 어떻게 싸울지는 직접 결정해주세요.”

동의 질문: “익명 메모를 과제 보고서에 사용하는 데 동의하시나요? 화면 녹화와 음성 녹음은 각각 동의 여부를 알려주세요.”

실제 빌드에서 확인한 조작 안내를 같은 문구로 제공한다. 기본 제공안은 이동 WASD, 마우스 조준·좌클릭 공격, Q 혈파, R 혈막, Space 회피, F 상호작용이다. 하수인 배치와 소환은 실제 화면에서 확인한 안내를 따른다. 효율적인 배치나 추천 전략은 설명하지 않는다.

## 관찰과 개입 규칙

- 전투 중 지속적인 발화를 요구하지 않는다. 웨이브 종료 후 “방금 어떤 점을 고려했나요?”처럼 짧고 중립적으로 묻는다.
- 시체 회수·소환을 스스로 발견하는지 보는 동안에는 먼저 해당 행동을 지시하지 않는다. 발견하지 못한 경우에도 종료 후 직접 체험 기회를 주려면 본 관찰 종료를 표시하고 별도 도움 체험으로 기록한다.
- 무입력 자체를 막힘으로 단정하지 않는다. 같은 실패를 반복하거나 진행 의도를 몰라 멈춘 경우 “지금 무엇을 하려고 하셨나요?”라고 묻는다.
- 참가자가 도움을 요청하거나 약 60초 동안 같은 문제로 진행하지 못하면 의도를 확인한 뒤 최소한의 조작 도움을 준다. 지연이 자동 침입에 영향을 주었는지도 기록한다.
- 도움 코드는 A0 도움 없음, A1 중립적 의도 확인, A2 조작·UI 위치 안내, A3 절차·해결 방법 안내, A4 진행자 조작이다. A1도 시점과 문구를 기록한다.
- 오류는 설계 문제와 구분한다. 오류로 플레이가 불가능하면 종료하거나 같은 시작 조건으로 복구하고 오염된 구간을 표시한다.
- “왜 그걸 안 했나요?”, “이게 더 좋지 않나요?”처럼 정답을 암시하는 질문은 피한다.

## 기록과 판단 방법

관찰 기록지는 참가자별 1부, 사후 설문지도 참가자별 1부를 사용한다. 시각은 본 플레이 시작을 00:00으로 기록한다. 사실·직접 발언·진행자 해석을 구분한다.

H1은 직접 전투와 하수인 역할을 행동 또는 사후 설명으로 확인한다. H2는 전략 변경 여부와 직전 결과를 근거로 한 이유를 확인한다. 같은 전략을 의도적으로 유지한 경우 이유를 기록한다. H3은 자연 관찰과 도움 후 체험을 분리하고, 시체 회수 기회가 있었는지 먼저 확인한다.

각 가설은 참가자별로 관찰 근거 있음 / 어려움 근거 있음 / 판단 보류 중 하나로 정리한다. 양쪽 근거가 함께 있으면 모두 적는다. 도움 수준을 함께 표시하며 도움을 받고 성공한 행동을 자력 성공으로 합치지 않는다.

3명의 결과는 인원수로 제시한다. 예를 들어 “3명 중 2명이 소환소 운반 위치를 찾는 데 도움 필요”처럼 기록한다. 이 표본만으로 전체 이용자의 선호나 난이도를 일반화하지 않는다. 설문 점수는 행동과 발언을 보완하는 자료로 사용한다.
