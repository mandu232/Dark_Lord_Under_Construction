# 웨이브 시스템

`SampleScene`에서 우측 하단 시작 버튼을 누르면 첫 침공이 시작됩니다. 다음 웨이브도 버튼을 눌러 시작합니다. 자동 대기 시간은 없습니다. 적은 던전 입구에서 생성되어 코어를 우선 공격합니다. 플레이어나 하수인이 가까이 있어도 먼저 공격하지 않으며, 피해를 받으면 가장 최근 공격자를 반격합니다. 반격 대상이 사망·비활성화·제거되면 코어로 복귀합니다. 반격 추적에는 아군 수호병의 방어 반경 제한을 적용하지 않습니다.

- 첫 웨이브: 적 3명, 체력 55
- 다음 웨이브: 적 수 +2, 적 체력 +10
- 웨이브 종료 보상: 혈액 12개부터 웨이브마다 +4
- 웨이브 시작: 우측 하단 시작 버튼 (자동 시작 없음)
- 일시정지 중에는 시작 버튼과 적 생성이 멈춥니다.
- 코어가 파괴되거나 플레이어가 사망하면 추가 웨이브 생성과 남은 적의 행동이 중단됩니다.
- 코어는 기존 보라색 타일 위치의 `Dungeon Core`이며, 기본 체력은 300입니다. `ActorHealth`에서 조정할 수 있습니다.

화면 상단 중앙 HUD에서 현재 웨이브, 시작 대기 상태, 생존한 적 수를 확인할 수 있습니다. 설정을 다시 연결해야 할 경우 `Tools > Dark Lord > Setup Wave System`을 실행합니다.

침입자 외형은 `Assets/Prefabs/Enemies/WaveInvader.prefab`에서 편집합니다. 스폰 코드가 SpriteRenderer 색상을 덮어쓰지 않습니다. 적 생성 간격·수·체력 증가·보상은 SampleScene의 `Wave System`에 있는 `WaveDirector` Inspector에서 조정합니다.
