# 입구와 파괴 모드

**B** 창은 방·하수인·함정·입구 탭과 **파괴 모드** 버튼을 제공합니다. 항목의 큰 상세 설명은 화면 오른쪽 별도 창에 표시됩니다. 두 창은 함께 열리고 닫힙니다. 인게임 미니언 상태창은 제거했습니다.

방·복도를 선택하면 건설창·상세 설명창·건설 열기 버튼을 숨기고 카메라를 줌 아웃해 배치 영역을 넓게 보여줍니다. 좌클릭으로 건설을 예약한 뒤 연속으로 배치할 수 있습니다. **우클릭**하면 현재 선택과 미리보기를 취소하고 원래 카메라 줌과 건설창을 복원합니다. 이미 예약한 건설은 유지됩니다. B/Esc로 건설 모드를 닫거나 일시정지하면 줌도 복원됩니다. WASD 이동은 배치 중에도 가능합니다.

URP 픽셀 퍼펙트 카메라에서는 배치 중 기준 해상도를 임시로 두 배 늘려 줌 아웃하며 기존 픽셀 설정을 유지합니다. 복원 시 원래 기준 해상도와 카메라 크기를 되돌립니다. 일반 직교 카메라는 크기를 두 배로 변경합니다.

배치 화면 검증: 전체 PlayMode 테스트 78개 통과. 실제 씬에서 320×180 / 카메라 크기 5.625가 배치 중 640×360 / 11.25로 변경되고, 취소 시 복원되는 것을 확인했습니다.

## 입구

입구 탭에서 용사 입구를 선택하고 코어와 연결된 완성된 빈 바닥을 클릭하세요. 입구는 하나이며 새 위치에 배치하면 기존 입구가 이동합니다. 코어 타일, 암석, 미완성 구역, 하수인·함정이 있는 칸에는 설치할 수 없습니다.

파괴 모드로 입구를 제거하면 바닥은 그대로 남습니다. 입구가 없는 동안 습격 준비 시간과 남은 적의 생성이 대기합니다. 다시 설치하면 이어서 진행하고, 이미 출현한 용사는 계속 행동합니다.

## 파괴

파괴 모드에서 하수인, 설치한 함정 또는 입구가 있는 칸을 좌클릭해 제거합니다. 다른 항목이나 카테고리를 선택하면 파괴 모드가 종료됩니다. B/Esc로 닫아도 배치가 중단됩니다.

하수인은 즉시 소환 인원과 명령 목록, 방 파수꾼 목록에서 빠집니다. 전투 사망 처리나 보상은 발생하지 않습니다. 함정 제거 후 같은 칸에 다시 설치할 수 있습니다. 플레이어·코어·용사·방·복도는 파괴 대상이 아닙니다.

기본 가시 함정은 지나가는 용사에게 1초 간격으로 12 피해를 주며 아군에는 피해를 주지 않습니다. 프리팹에서 Damage와 Cooldown을 수정할 수 있습니다.

## 시작 던전과 7×7 방

시작 코어 방은 7×7 방 디자인, 기존 통로는 연결된 5×3 복도 디자인으로 생성됩니다. 방 탭에서 기존 5×5 방과 새 7×7 방을 선택할 수 있습니다. 7×7 방은 14×14 월드 유닛이며 기존과 같이 복도에 연결해야 합니다. 전체 49칸이 열린 뒤 지정한 프리팹이 생성됩니다. 큰 방에서도 모든 파수꾼을 처치한 뒤 용사가 다음 방으로 이동합니다.

항목 설정은 Assets/Data/Construction, 방·입구·함정 프리팹은 Assets/Prefabs/Dungeon, 아이콘은 Assets/Art/UI/Construction, 메시 원본은 Assets/Art/Dungeon/Meshes에 있습니다. DungeonGrid의 Initial Room Prefab과 Initial Corridor Prefab으로 시작 디자인을 교체할 수 있습니다.

검증: 전체 PlayMode 테스트 77개 통과. 입구 이동·삭제·재설치와 습격 재개, 하수인 인원 해제, 함정 피해 대상과 제거 후 재설치, 7×7 방 연결·파수꾼 이동 제한, 시작 구역 크기를 검사했습니다. 실제 씬에서 분리된 우측 설명창과 미니언 HUD 제거, 초기 디자인 4개 생성, 입구 배치·파괴·재설치를 확인했습니다.
