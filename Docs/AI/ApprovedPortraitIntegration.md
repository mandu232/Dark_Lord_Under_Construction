# 승인 초상화 게임 적용

최신 외곽선 없는 릴리아 시안과 픽셀 크기를 수정한 로웬·니블, 후광을 제거한 루브 이미지를 게임 리소스로 복사했다.

- 릴리아·로웬: 튜토리얼 대화창 양쪽. 상반신 구도에 맞춰 높이 600, 화면 안쪽 앵커로 조정했다. 검은 대화창과 화자 강조를 유지한다.
- 니블: 상인 거래창 왼쪽에 표시하며, 거래창 이름을 니블 틱 · 던전 컴퍼니로 표시한다.
- 루브: 재건 훈련 안내 옆에 표시한다. 소환창이 열려 안내가 왼쪽으로 옮겨지면 루브는 안내의 오른쪽으로 옮겨 화면 밖으로 나가지 않게 한다.
- 캐릭터 이동 스프라이트는 기존 애니메이션을 사용한다. 새 이미지들은 UI 초상화다.

리소스: `Assets/Resources/Story/Portraits/LiliaDungeon.png`, `RowenDungeon.png`, `NibbleDungeon.png`, `RubeDungeon.png`.

원본 알파와 종횡비를 보존한다. Point 필터, 무압축, Clamp, 밉맵 없음으로 가져왔다. 재임포트는 `Tools/ImportDungeonPortraits.cs`를 Unity eval_file로 실행한다.

대화 관련 Play Mode 테스트 35개 통과. 화면 검증 캡처는 `output/dialogue-review/applied/`에 기록한다.

최종 배치로 관련 테스트 35개를 다시 통과했다. 1920×1080 및 1024×768에서 대사 13줄 모두 overflow=False이고, 니블 거래창 및 루브 안내도 캡처하여 확인했다. 상반신 얼굴이 이름표에 가려지지 않도록 위치를 올렸다. 거래창에서 실제 구매 성공과 금화 250→150 차감을 확인했다. ResourceEconomy 필터는 검색 결과 0개여서 이 검증을 자동 테스트 통과로 계산하지 않는다.

## 화면 양끝 배치

릴리아·로웬을 대화창 자식에서 별도의 화면 전체 Dialogue portraits 영역으로 옮겼다. 릴리아는 화면 왼쪽, 로웬은 화면 오른쪽에서 각각 16 기준 픽셀의 여백을 둔다. 높이 600과 세로 위치는 유지한다. 두 초상화 영역은 대화가 열릴 때만 표시하며 로웬의 대사별 등장 상태를 유지한다. 기존 대화 테스트에 좌우 화면 경계와 여백 검사를 추가했다.

화면 양끝 배치 검증: Unity 컴파일 및 관련 Play Mode 테스트 36개 통과. 1920×1080과 1024×768 실제 Game View에서 좌우 배치와 대사 표시를 확인했다. 캡처는 output/dialogue-review/screen-edges/에 있다.
