# 전투 연계 증강과 카드 보상창

2026-10-22. 기존 WaveDirector 보상/웨이브 전환과 전투 호출 지점을 확장한다. 씬·기존 프리팹 재작성이나 패키지 추가는 없다.

## 선택 규칙

- 1~4웨이브 클리어 시 미보유 증강 중 무작위로 서로 다른 세 가지를 제시한다.
- 하나를 선택하면 이번 원정의 이후 전투에 계속 적용된다. 같은 증강을 중복 획득하지 않는다.
- 기본 클리어 혈액과 시설 생산, 선택 중 일시정지 및 선택 후 생존자 회복은 유지한다.
- 5웨이브는 다음 전투가 없으므로 기존 금화·혈액·혈석·최대 체력·코어 수리 중 세 가지 전리품을 제시한다. 온전한 코어에는 수리 보상을 제시하지 않는다.
- 이전 보상 ID 0~4는 그대로 유지한다. 새 ID 5~10은 WaveRewardCatalog에서 관리한다. 보상 후보가 저장되므로 재로드로 다시 추첨하지 않는다.

## 효과

| ID | 이름 | 발동과 효과 |
|---|---|---|
| 5 | 응고된 혈파 | 둔화 중인 적에게 혈파의 마법 피해 +25. 실제 적중마다 마나 +5, 시전당 최대 +15. |
| 6 | 마왕의 사냥감 | 마왕 근접 공격이 적에게 4초 표식. 하수인의 다음 공격이 소모하여 추가 피해 18. |
| 7 | 끈질긴 권속 | 하수인의 공격이 적을 1.25초 동안 35% 둔화. 기존 strongest-slow 규칙과 저장을 사용. |
| 8 | 사냥터의 낙인 | 피해/둔화 함정 발동 시 살아남은 적에게 4초 낙인. 마왕의 다음 근접 공격이 소모하여 추가 피해 20. |
| 9 | 혈막의 맹약 | 혈막 사용 시 4유닛 내 보이는 살아 있는 하수인을 20 회복. 5초 내 다음 공격에 추가 피해 15. |
| 10 | 권속의 공물 | 하수인 처치 시 마왕 마나 +8, 혈파 남은 쿨다운 -1초. 마지막 적 처치도 처리. |

공통: 침입 중에만 발동하며 아군/다른 씬을 대상으로 하지 않는다. 추가 근접/하수인 피해는 해당 공격의 원래 피해 타입과 내성 계산을 따른다. 표식·낙인·강화는 각각 한 번 소모되며 함께 적용될 수 있다. 둔화와 타이머는 scaled time을 사용한다.

권장 조합: 끈질긴 권속 + 응고된 혈파 / 마왕의 사냥감 + 혈막의 맹약 / 사냥터의 낙인 + 직접 근접 공격 / 권속의 공물 + 혈파로 적 약화 후 하수인 마무리.

## UI와 아트

- WaveRewardPanel: 화면을 어둡게 한 모달 위 가로 세 카드, 아이콘, 연계 대상, 이름, 구체적 효과, 지속 기간, 선택 버튼, 보유 증강 목록.
- SaveCardHoverLift의 unscaled 호버 동작 재사용. 전체 카드 클릭과 키보드 좌우 순환/선택 지원. 입력을 막는 배경과 고정 카드 히트 영역을 사용한다.
- GameMenu를 Esc로 열면 선택창을 잠시 숨기고, 메뉴를 닫으면 보상 선택으로 돌아온다. 선택 자체가 게임 상태를 전환한다.
- CombatHud는 획득 증강 이름과 최근 발동 효과를 표시한다. AugmentStatus는 표식/낙인/하수인 강화의 머리 위 아이콘을 표시한다.
- Assets/Resources/WaveRewardSkin.asset이 기존 UI 스프라이트를 직접 참조한다: SaveCardFrame, CastleButton, StickyTrap, GuardIcon, SpikeTrapIcon, PendantRuby, ResourceIconSheet.
- Tools/SetupWaveRewardSkin.cs를 Unity eval_file로 실행하면 스킨 참조를 재생성한다. 원본 PNG나 임포트 설정은 변경하지 않는다.

## 저장 호환

WaveSaveData.augments와 MinionSaveData.augmentStatus는 버전 1의 선택 필드다. 누락하면 미보유/효과 없음으로 복원한다. 후보, 보유 증강, 적의 두 표식, 하수인 강화 잔여 시간을 저장한다. 기존 slows 필드가 둔화를 보존한다. 저장 검증은 잘못된 ID, 중복 보유/후보, 보유한 증강의 재제시, 잘못된 시간 값을 거부한다.
