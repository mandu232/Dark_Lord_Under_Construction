# 대사 연결과 로웬 퇴장 수정

## 원인과 수정

초상화 UI는 화자의 색상만 갱신하고 로웬의 등장 여부를 갱신하지 않아, 혼자 하는 대화에서도 로웬 초상화가 남아 있었다. DialogueEntry에 RowenPresent를 두고 UI는 매번 해당 상태로 활성 여부를 갱신한다. 초기 대화는 배우가 아직 전투용으로 스폰되기 전이므로 월드 배우 존재 여부 대신 대화 장면의 등장 상태를 사용한다.

로웬은 붕괴 직전 후퇴 후 안쪽 대화, 마지막 철수 대사 이후의 독백, 소환 이후에는 보이지 않는다. 이 상태는 저장된 대사 위치에서 다시 계산하므로 저장 형식을 바꾸지 않는다.

오프닝 마지막에 입구의 발소리를 넣고, 첫 대화는 로웬이 릴리아의 도면을 발견하며 시작한다. 퇴장 뒤에는 루브와 도면을 다시 펴고, 소환 후에는 중단된 설계를 마저 보도록 연결했다. 붕괴 전 대사에서 이미 붕괴가 끝난 것처럼 말하던 문장도 지지대의 균열을 경고하는 내용으로 수정했다.

## 검증

대화·튜토리얼 관련 Play Mode 테스트 36개 통과. 대사별 등장 상태와 퇴장 후 저장 복원 테스트를 포함한다. 최신 전체 문안은 Docs/스토리_대사_개정_2026-10-23.md에 기록했다.

실제 1920×1080·1024×768 Game View에서 대사 13줄을 모두 확인했고 글자 넘침이 없었다. 수정된 오프닝 마지막 자막도 실제 프리팹으로 확인했다. OpeningStoryTests 필터는 이번 실행에서 0개를 반환하여 테스트 통과 수에 포함하지 않았다.
