# 용사 병과와 5웨이브 편성

2026-10-22. 새 씬/프리팹 연결 없이 기존 WaveDirector, MinionController, WaveHud를 확장한다.

## 일반 난이도 편성

| 웨이브 | 전사 | 방패병 | 치유사 | 돌격병 | 대응 |
|---|---:|---:|---:|---:|---|
| 1 | 3 | 0 | 0 | 0 | 기본 저지와 함정 |
| 2 | 3 | 0 | 0 | 2 | 돌진 예고 회피, 둔화 |
| 3 | 6 | 0 | 1 | 0 | 치유사 우선 제거, 시전 차단 |
| 4 | 6 | 2 | 1 | 0 | 측후방/마법과 치유 차단 |
| 5 | 3 | 3 | 2 | 3 | 세 병과 혼합 대응 |

난이도별 전체 인원은 기존 NewGameOptions 배율을 따른다. WaveFormation이 실제 생성과 예고에 같은 편성을 공급한다. 체력은 기존 웨이브/난이도 계산을 유지한다. 난이도 적용 시 Changed를 발행하므로 지연 적용되는 새 게임 옵션도 UI에 반영된다.

## 행동과 표식

- 방패병: 바라보는 방향 ±60도에서 오는 물리 피해를 70% 줄인다. 마법, 측후방, 출처 없는 바닥 함정은 이 방패 감쇄를 받지 않는다. 머리 위 파란 사각형과 전면 파란 방패선.
- 치유사: 5.5유닛 안의 부상 아군(자신 제외)에게 0.8초 시전 후 체력 18 회복. 재사용 4초. 시야, 생존, 거리 재확인. 피해를 받으면 시전 취소 후 2초 재시도 대기. 초록 십자와 시전 표시.
- 돌격병: 1.3~6유닛의 보이는 목표 방향을 0.75초 예고한 뒤 고정 방향으로 0.65초간 2.6배 속도로 돌진. 충돌 시 물리 피해 22를 한 번 주고 0.65초 회복. 재사용 6초. 기존 물리 충돌과 둔화 적용. 붉은 머리 표식과 지면 방향선.
- 공통: 기존 용사 아트와 애니메이션을 재사용한다. 전용 병과 아트/사운드는 추가하지 않았다. 타이머는 scaled time을 사용하며 정지 중 진행하지 않는다.

## UI와 저장

- 준비 중 우측 하단: 편성 제목, 실제 병과별 인원, 총 인원/개별 체력, 대응 팁, 표식 범례. 침입/보상/종료 시 숨긴다.
- 기존 상단 상태에도 다음 편성 제목과 인원을 표시한다. 기존 시작 버튼을 유지한다.
- 버전 1의 선택 필드로 병과/행동/남은 시간/돌진 방향/치유 대상 위치와 남은 출현 순서를 저장한다. 재로드 시 치유 대상은 저장 위치에 가장 가까운 유효 부상 아군으로 다시 찾는다.
- 기존 저장에서 해당 필드가 없으면 기존 전사와 전사 대기열로 복원한다. 잘못된 병과/타이머/대기열 길이는 저장 검증에서 거부한다.

## 검증

- Unity Editor 컴파일 통과.
- InvaderRoleTests: 10개. 정면/측후방/마법 방어, 회복/차단/사거리/벽, 돌진/단일 타격/둔화/일시정지/물리 벽/콜라이더 없는 코어, 난이도 반영, 5웨이브 예고와 대기열, 실제 저장 후 전체 출현, 기존 저장 호환 및 잘못된 기록 거부.
- 기존 CoreCombatLoopTests 13개와 AreaTrapTests 5개는 전체 실행에서 통과.
- SaveGameTests 단독 실행 7/7 통과.
- 1920x1080 실제 Game View에서 마지막 웨이브 예고와 병과/시전/돌진 표식을 확인. Temp/wave-formation-ui.png, Temp/invader-role-ui.png.
- Windows 플레이어 빌드와 장기 밸런스 플레이테스트는 수행하지 않았다.

## 전체 테스트의 한계

중간 전체 실행 164개 중 138개 통과, 26개 실패. 신규 병과 8개(이후 10개로 확대), 핵심 전투 13개, 함정 5개는 통과했다. 실행 초기 timeScale=0 때문에 이동 테스트가 정지했으며, 일부 메뉴 테스트는 현재 방/탭/아트 구성과 맞지 않는 기대값 또는 null 참조를 보고했다. 스토리 테스트가 InGame을 Single 로드한 뒤 후속 Additive 로드 테스트에서 중복 전역 조명 오류가 발생했다. 저장 테스트는 이후 단독 재실행으로 7/7 통과했다. 이 전체 실행을 전체 프로젝트 회귀 통과로 간주하지 않는다. 나머지 실패의 변경 전 재현 여부는 확인하지 않았다.
