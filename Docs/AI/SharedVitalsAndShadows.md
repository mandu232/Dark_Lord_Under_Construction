# Shared core/player health, HUD bars and larger contact shadows

Implemented 2026-10-31.

`ActorHealth` now supports linking another body to one authoritative health owner. `WaveDirector.Start` links the core to the player: the player's base 100 HP becomes the initial shared pool. Health reads, damage, healing, maximum-health changes and death through either body use that pool. Damage is applied once per received hit. Both bodies receive damage/death notifications, and WaveDirector handles defeat once. Target-specific armor and dodge/ward checks stay on the body actually struck; tutorial health floors protect the shared pool. Unlinked minions, enemies and facilities retain independent health.

Core repairs, player healing, vitality research and core vitality research all change the same pool. A zero pool kills both bodies; Heal cannot resurrect either. The old independent core's 300 base HP is not added to a new run's player HP. `GameSaveData.sharedCoreHealth` marks new records, whose player/core health values must match. Legacy records use player maximum HP plus purchased core maximum bonuses above the former 300 base; current HP uses the lower of the two old health percentages. This retains upgrades and prevents legacy loading from reviving an already dead body. New records round-trip without repeating that conversion.

GameHud builds a red **공유 체력** bar and a blue **마나** bar next to the existing pendant artwork. The existing health label becomes the health-bar value label; mana amount/fill follows PlayerCombat and actual spell costs/regeneration. CombatHud no longer repeats separate numeric core HP/mana text. The core technology summary and health-research descriptions use shared-health wording.

Contact shadow enlargement: character ellipse width/height increased by 40% without moving their authored feet. Facility/core contact silhouettes now scale to 1.13 horizontally and 1.04 vertically, shifted down 1.5 source pixels, expanding the dark rim beneath the base. Source art, long projected shadows and held-character hiding behavior are preserved.
