# 던전 생성과 한 칸 확장

`Assets/Scenes/SampleScene.unity`에 연결되어 있습니다. Play를 누르면 41×31칸의 던전을 생성합니다. 한 칸은 1 Unity 유닛이며 기존 16 PPU 기준과 일치합니다.

2026-09-20부터 일꾼은 시작 시 배치되지 않습니다. 먼저 **V → Summon worker**로 소환한 뒤 창을 닫고 채굴을 지정하세요. [하수인 소환](MinionSummoning.md)을 참고하세요.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 기존 플레이어 이동 |
| B | 던전 확장 모드 켜기 / 끄기 |
| 왼쪽 클릭 | 암석에 일꾼 채굴 작업 예약 / 예약된 칸을 다시 클릭하면 취소 |
| Esc | 확장 모드 종료 |

B를 누르고 갈색 암석을 클릭하면 작업이 예약됩니다. 플레이어가 암석 옆에 갈 필요는 없습니다. 노란 모자와 곡괭이를 가진 주황색 일꾼이 바닥 경로를 따라 이동하고, 대상 암석 바로 옆에서 기본 2초 동안 채굴한 뒤 바닥으로 바꿉니다. 예약한 칸은 금색이며 채굴 진행에 따라 청록색으로 변합니다. HUD에 일꾼 상태·남은 작업 수·진행률이 표시됩니다.

여러 칸을 예약할 수 있습니다. 현재 접근 불가능한 작업은 대기시키고 다른 접근 가능한 작업을 우선 수행합니다. 앞쪽 암석을 채굴해 길이 열리면 안쪽 작업도 자동으로 이어서 수행합니다. 중복 예약은 생성하지 않으며 예약한 칸을 다시 클릭하면 이동/채굴 중에도 취소합니다. B 또는 Esc로 모드를 닫아도 작업은 계속됩니다. 오른쪽 클릭·Q·E의 기존 전투 하수인 명령은 유지되며 일꾼에게 적용되지 않습니다.

## 초기 맵과 규칙

- 중앙 7×7 시작 방과 왼쪽 입구를 잇는 폭 3칸의 통로를 생성합니다. 현재 플레이어와 하수인 위치를 수용하도록 씬의 던전 원점을 배치했습니다.
- 회색은 바닥, 갈색은 암석, 짙은 색의 외곽은 기반암입니다. 보라색 코어·파란색 입구는 위치 표시이며 아직 전투 목표나 웨이브 기능이 없습니다.
- 암석과 기반암은 Collider2D로 이동을 막습니다. 확장 즉시 해당 암석 충돌이 해제됩니다.
- 바닥·기반암·지도 밖은 지정할 수 없습니다. 실제 채굴은 일꾼이 상하좌우로 인접한 바닥에 도착한 뒤에만 진행합니다.
- 플레이어 사망·일시정지·입력 컴포넌트 비활성화 시 새 작업 지정을 차단합니다. UI 위 클릭은 지형에 전달하지 않습니다. 예약된 작업은 플레이어 사망 후에도 살아 있는 일꾼이 계속 수행합니다.
- 일시정지하면 일꾼 이동/채굴도 정지합니다. 일꾼이 피격되면 0.5초 중단하고 진행도를 유지해 재개합니다. 사망하면 이동/채굴/충돌을 중단합니다. V로 새 일꾼을 소환할 수 있으며, 대체 시 이전 작업 예약은 취소됩니다. 작업 인계·부활은 아직 없습니다.
- 일꾼은 시작 시 존재하는 아군 캐릭터와의 충돌만 무시하고 지형과 적은 통과하지 않습니다. 전투 능력과 적 접근 시 대피 기능은 아직 없습니다.
- 채굴 비용과 석재 보상은 아직 없습니다. 벽 설치, 방 지정, 준비/침입 단계 제한, 저장·불러오기는 후속 기능입니다. Play 종료 후 확장 기록과 예약은 초기화됩니다.

## 타일맵 확장 지점

`DungeonLayout`이 칸 상태와 연결 규칙을 소유합니다. `GetCell`, `IsFloor`, `CanExpand`, `TryExpand`, `CellChanged`가 후속 타일맵·건설의 연결 지점입니다. `DungeonGrid`는 Unity `Grid`로 월드 좌표와 칸 좌표를 변환합니다.

현재 표현은 하나의 Mesh와 버텍스 색상을 사용하므로 스프라이트·텍스처가 필요 없습니다. 추후 `DungeonGrid`의 표현/충돌 처리를 Tilemap/TilemapCollider2D로 교체하고 `CellChanged`에서 해당 타일을 갱신할 수 있습니다. 플레이어 입력과 칸 상태를 함께 다시 작성할 필요는 없습니다.

`WorkerMiner`가 한 일꾼의 작업 대기열·채굴 진행도를 소유하고 바닥의 상하좌우 경로를 BFS로 탐색합니다. 입력은 `QueueMining` / `CancelMining`에 연결됩니다. `DungeonExpansion.TryExpand`는 기존 이름을 유지하지만 이제 직접 지형을 변경하지 않고 예약/취소합니다. 실제 지형 변경은 채굴 완료 시 `DungeonGrid.TryExpand`로 수행합니다.

`DungeonTerrain` 레이어는 기존 전투 하수인과 명령 컴포넌트의 장애물 마스크에 연결되어 있습니다. 일꾼은 격자 경로 탐색을 사용하지만 전투 하수인의 미로 우회 경로 탐색은 아직 없습니다.

## 씬 설정

다른 씬에는 `PlayerMovement`와 Main Camera가 있는 상태에서 `Tools > Dark Lord > Setup Dungeon Expansion`을 실행하고 씬을 저장합니다. 반복 실행 시 던전과 플레이어 컴포넌트를 중복 생성하지 않습니다. 기존 던전 크기/원점은 유지합니다. 생성 시 기본 방 중앙이 현재 플레이어 위치입니다.

플레이어의 `DungeonExpansion`에는 던전·카메라·일꾼이, 일꾼의 `WorkerMiner`에는 던전이 연결됩니다. `Mining Seconds`에서 칸당 채굴 시간을 조정합니다. 기본 일꾼은 1명이며 작업 대기열 공유·여러 일꾼 배정은 현재 범위에 포함하지 않습니다. 설정 메뉴는 기존 일꾼을 재사용합니다.

던전의 `DungeonGrid`에는 프리뷰 머티리얼이 연결됩니다. 크기는 Inspector에서 변경할 수 있습니다. 기본 크기 변경 시 던전 원점과 플레이어 시작 위치를 함께 확인하세요. 일꾼 외형도 Mesh 기반이므로 스프라이트가 필요 없습니다.

## 검증

`DungeonExpansionTests`는 초기 통로, 외곽·입구·코어 보호, 연속 확장, 중복 확장 방지, 좌표 변환, 작업자 인접 조건, 실제 물리 충돌 및 확장 후 통행, 확장 모드·사망·일시정지 조건을 검사합니다. 기존 메뉴 `Tools > Dark Lord > Run Gameplay Tests`에 포함됩니다.

2026-09-19 Unity 6000.6.2f1에서 전체 PlayMode 테스트 21개 통과(일꾼 4개, 던전/입력 6개, 기존 이동/전투/애니메이션 11개). B → 클릭은 즉시 파괴하지 않고 예약하며, Esc 후 예약이 유지되는 것을 검사했습니다. 연속 채굴·접근 불가 작업 재개·취소·중복 방지·경로의 코너 회피·피격/사망/일시정지 처리도 검증했습니다.

2026-09-29: 타일을 32×32픽셀(16 PPU 기준 2×2 월드 유닛)로 확대했습니다. 미니언 크기는 유지하며 소환 위치는 선택한 셀의 중심입니다. 바닥 메시, 벽 충돌, 좌표 변환과 씬의 던전 원점/코어를 함께 조정했습니다. 소환 범위는 기존 3칸이며 이동 속도와 전투 거리는 월드 유닛 기준을 유지합니다.
