# 하수인 소환

**2026-10-06 통합:** **B → 하수인 탭**에서 호위병을 선택합니다. 별도 소환 창은 제거되었습니다. [통합 던전 설계 창](UnifiedConstruction.md)을 참고하세요.

시작 씬에는 하수인이 없습니다. 통합 창에서 기본 최대 4명까지 배치할 수 있습니다. 일꾼 소환과 상태 표시는 제거되었습니다.

호위병 선택 후 플레이어 주변 3칸 이내의 빈 바닥을 좌클릭하면 해당 타일 중앙에 소환됩니다. 초록색은 배치 가능, 빨간색은 배치 불가입니다. 암석, 지도 밖, 다른 캐릭터와 겹치는 위치에는 배치할 수 없습니다. 우클릭 또는 Esc로 배치를 취소합니다.

우클릭으로 하수인 전체를 이동시키는 기능은 제거되었습니다. Q 집결은 제거되었으며 **E 복귀**는 유지됩니다. 건설창에서 배치 중에도 WASD 이동은 가능하며, 호위병 명령 입력은 차단됩니다.

**B 건설창 → 방·복도 선택 → 연결된 위치 클릭**으로 확장합니다. 일꾼 없이 타일이 짧게 번쩍이고 파편을 흩뜨리며 순차적으로 바닥으로 바뀝니다. 자세한 규칙은 [던전 건설](DungeonConstruction.md)을 참고하세요.

소환 비용은 현재 무료입니다. 사망한 호위병은 인원 제한에서 즉시 제외되며, 시체는 사망 애니메이션 후 1.5초 뒤 삭제됩니다. 살아 있는 호위병의 수비 자리는 전투로 이동해도 예약되며 사망 또는 제거 시 해제됩니다. Guard Limit에서 상한을 조절합니다. Setup Minion Summoning 메뉴는 호위병 프리팹과 던전 참조를 연결하며 일꾼을 생성하지 않습니다. 기존 일꾼 코드와 프리팹은 이전 기능 자료로 보존하지만 게임에서는 사용하지 않습니다.

2026-10-06 전체 PlayMode 테스트 71개 통과: 일꾼 소환 차단, 일꾼 없는 순차 건설, 일시정지, 호위병 배치와 우클릭 취소, 일반 우클릭 이동 명령 제거를 포함합니다.
