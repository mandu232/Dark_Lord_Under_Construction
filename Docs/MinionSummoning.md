# 하수인 소환

시작 씬에는 하수인이 없습니다. Play 후 **V**를 누르면 소환 창을 엽니다.

- `Summon worker`: 일꾼 배치 모드 선택. 현재 살아 있는 일꾼은 최대 1명입니다.
- `Summon guard`: 수호 하수인 배치 모드 선택. 기본 최대 4명입니다.
- **V / Esc / Close**: 창 닫기.

종류를 선택하면 창이 사라지고 타일 선택 모드로 전환됩니다. 커서 아래 타일이 **초록색이면 배치 가능**, **빨간색이면 배치 불가**입니다. 원하는 칸을 **좌클릭**하면 그 칸 중앙에 소환됩니다. 잘못된 칸을 클릭해도 소환되지 않고 선택 모드를 유지합니다. **우클릭 / Esc**로 취소하고, 선택 중 **V**로 종류 선택 창으로 돌아갈 수 있습니다. 소환 완료 후 선택 모드는 종료됩니다.

소환 위치는 플레이어와 연결된 주변 3칸 이내의 비어 있는 바닥에서 직접 선택합니다. 암석, 지도 밖, 다른 캐릭터와 겹치는 곳에는 소환하지 않습니다. 불가 사유는 화면 아래 안내에 표시합니다. 소환 창과 타일 선택 모드 동안 플레이어 이동·채굴 지정·전투 하수인 명령 입력은 차단하지만, 게임 시간과 이미 진행 중인 일꾼 작업·전투는 계속됩니다. 취소에 사용한 우클릭은 같은 프레임에 수비 명령으로 전달되지 않습니다.

현재는 자원 시스템 연결 전이라 무료입니다. 마나 비용, 식량, 침입 단계 제한, 코어 주변 전용 소환은 후속 기능입니다. 일꾼 1명은 현재 단일 채굴 대기열 구조에 맞춘 제한이고, 수호 하수인 4명은 초기 기획 상한입니다. `MinionSummoning > Guard Limit`에서 수호 하수인 상한을 조절할 수 있습니다.

소환된 일꾼은 자동으로 채굴 입력에 연결됩니다. 창을 닫고 **B → 암석 클릭**으로 작업을 예약하세요. 소환된 수호 하수인은 자동으로 명령 목록에 들어가 **오른쪽 클릭 / Q / E** 명령을 받습니다. 죽은 하수인은 살아 있는 수 제한에서 제외되어 다시 소환할 수 있습니다. 죽은 일꾼을 대체할 때 이전 작업 예약을 정리하며 새 일꾼에게 자동 인계하지 않습니다.

기존 시작 배치의 일꾼·수호 하수인 설정은 `Assets/Gameplay/Prefabs/Minions/SummonWorker.prefab`, `SummonGuard.prefab`으로 보존했습니다. 씬에는 플레이어의 `MinionSummoning`과 던전/프리팹 참조만 남겼습니다. `Tools > Dark Lord > Setup Minion Summoning`은 이 설정을 연결하고 시작 배치 아군 하수인을 제거하는 Editor 메뉴입니다. 반복 실행해도 소환 컴포넌트는 중복되지 않습니다.

2026-09-20 Unity 6000.6.2f1에서 전체 PlayMode 테스트 **29개 통과**. 빈 시작 상태, 소환 인원 제한, 충돌 없는 배치, 일꾼 채굴 연결, 전투 명령 목록 등록, 사망 후 재소환, 공간 부족·일시정지·사망 시 차단, V/Esc 입력 및 메뉴 중 이동 차단을 검사했습니다. 타일 선택 후 정확한 칸 중앙 배치, 잘못된 칸 거절, 취소, 실제 마우스 좌클릭 배치·우클릭 취소도 검사했습니다.
