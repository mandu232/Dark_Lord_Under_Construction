# 하수인 정보 확인

- 살아 있는 아군 하수인 위에 마우스를 올리면 스프라이트 가장자리에 흰 테두리가 나타납니다.
- 우클릭하면 오른쪽에 현재/최대 체력, 공격력, 공격 간격, 공격·감지 거리, 이동 속도와 행동 상태를 표시합니다.
- 선택한 하수인 정보는 0.1초 간격으로 갱신됩니다. 다른 하수인 우클릭으로 대상을 바꿉니다.
- 빈 공간 우클릭 또는 × 버튼으로 닫습니다. 사망, 일시정지, 건설·배치 시작 시에도 닫힙니다.
- 건설 및 배치 중에는 기존 우클릭 취소가 우선합니다.

구현: MinionInspectionPanel / SpriteHoverOutline 셰이더.
UI 재생성: Tools > Dark Lord > Setup Minion Inspection 또는 Setup Basic Game UI.
테두리는 스프라이트 내부 가장자리 1픽셀에 표시되며 애니메이션 프레임에 맞춰 갱신됩니다. 마우스가 벗어나면 기존 머티리얼을 복원합니다.

정보창은 화면 오른쪽 중앙보다 약간 아래에 배치합니다. 마우스 판정은 애니메이션 프레임의 물리 외곽선(Physics Shape)을 사용해 투명 여백을 제외하며, 좌우·상하 반전과 오브젝트 크기를 반영합니다. 프레임별 외곽선을 캐시하여 매 프레임 배열을 생성하지 않습니다.
