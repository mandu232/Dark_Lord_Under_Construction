# 하수인 재배치와 방별 한도

- 배치된 하수인을 좌클릭으로 0.3초 이상 누른 뒤 빈 칸에 놓으면 재배치합니다.
- 우클릭 상태창의 재배치 버튼으로도 목적지를 좌클릭해 옮길 수 있습니다.
- 우클릭/Esc, 일시정지, 플레이어 사망, 잘못된 곳에 드롭하면 이동을 취소합니다. 원래 인스턴스와 체력을 유지합니다.
- 소환은 주인공 3칸 이내, 재배치는 연결된 완성된 방으로 가능합니다. 입구/함정/건물/점유된 칸에는 배치할 수 없습니다.
- 일반 방 2명, 큰 방/핵심 방 4명. Player의 MinionSummoning에서 Small Room Limit / Guard Limit를 조절합니다.
- 방 인원은 살아 있는 하수인의 방어 위치를 기준으로 계산합니다. 전투 이동으로 한도가 풀리지 않으며, 사망과 다른 방으로 재배치하면 자리가 해제됩니다.
- 과거 저장의 기존 하수인은 유지하고 추가 배치 때 한도를 검사합니다. 새 방어 위치는 기존 저장 시스템에 저장됩니다.
- 상태창 Relocate 버튼과 Placement Hint는 SampleScene의 HUD 아래 Minion Inspection UI에서 편집할 수 있습니다.

## 재배치 시각 효과와 방 인원 표시

- 재배치 시 건설 배치와 같은 2배 줌아웃을 사용합니다. URP PixelPerfectCamera 참조 해상도도 함께 조정하며, 두 모드가 겹쳐도 중복 확대하지 않습니다.
- 커서 위에 원래 하수인의 스프라이트를 살짝 크게 표시하고 그림자와 작은 떠오름 움직임을 추가합니다. 원래 하수인은 반투명하게 남고 실제 위치는 배치 성공 때 변경됩니다. 불가능한 위치는 붉은색으로 표시합니다.
- Player의 MinionRelocationVisuals에서 Lift Height / Held Scale을 조정할 수 있습니다.
- 건설 모드 또는 재배치 모드에서 완공된 방 중앙에 아이콘 슬롯과 현재 인원 / 한도를 표시합니다. 평상시와 일시정지 중에는 숨깁니다.
- Assets/Prefabs/UI/RoomCapacityLabel.prefab에서 배경, 글자와 아이콘 슬롯 크기를 편집합니다.
- 게임 HUD의 Room Capacity Overlay > Skull Icon에 향후 해골 Sprite를 지정하면 모든 방에 적용됩니다. 아이콘이 없을 때는 반투명 빈 슬롯이 표시됩니다.

## 하수인 AI 선택

우클릭 상태창의 재배치 버튼 위에서 공격적/수비적을 선택합니다. 기본값은 수비적입니다.

- 수비적: 배치 위치를 중심으로 Detection Range 안에 있는 적을 공격하며, 범위 밖으로 나가면 복귀합니다.
- 공격적: 배치된 방 안의 적을 감지하고 공격하며, 방 밖으로 추격하지 않습니다. 방이 없는 예전 배치에서는 수비적 범위를 사용합니다.
- 두 모드 모두 적대 진영, 살아 있는 대상과 시야 조건을 검사합니다. 모드를 변경하면 이전 공격 대상을 해제하고 다시 탐색합니다. 용사의 침공 경로 AI는 유지됩니다.
- 재배치 및 저장/이어하기에서도 선택 모드를 유지합니다. AI 필드가 없는 이전 저장 기록은 수비적으로 복원됩니다.

하수인·건물 상태창은 체력 숫자 아래에 InspectionHealthBar를 표시합니다. 체력 비율에 따라 초록/노랑/빨강으로 변하며, 제목·본문 크기와 줄 간격을 키우고 불투명 배경을 사용합니다.

## 이름과 선택 테두리

현재 하수인의 이름은 혈액 슬라임입니다. MinionController의 Display Name을 하수인 프리팹마다 지정하면 정보창에서 해당 이름을 표시합니다. 건설 카드 이름은 해당 BuildItemDefinition의 Display Name에서 설정합니다. HUD의 전체 인원은 종을 구분하지 않는 하수인으로 표시합니다.

상태창에서 확인 중인 하수인의 테두리는 커서가 벗어나도 유지됩니다. 다른 하수인을 호버하면 양쪽에 테두리가 표시되며 각 스프라이트의 애니메이션 UV를 독립적으로 갱신합니다. 상태창을 닫거나 다른 대상으로 전환하고, 선택 대상이 죽거나 건설/재배치/일시정지 모드에 들어가면 선택 테두리를 해제합니다. 해당 하수인을 계속 호버 중이면 호버 테두리는 남습니다.
